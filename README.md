# Calcora | Smart Calculator

Calcora is a responsive calculator web application built with HTML, Tailwind CSS, and JavaScript. It provides a clean, user-friendly interface for performing both standard and scientific calculations.

## Features

- Standard calculator operations (addition, subtraction, multiplication, and division)
- Scientific calculator functions
- Percentage and sign-change operations
- Dark and light themes
- Keyboard support
- Responsive design
- Error handling for invalid calculations

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Heroicons (SVG icons)

## Purpose

This project was created as part of my web development learning journey to strengthen my frontend development skills and gain practical experience working with HTML, Tailwind CSS, and JavaScript.
